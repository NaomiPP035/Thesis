首次连接 / 开发板设置

使用桌面 Chrome 或 Edge，通过 localhost 或 HTTPS 打开本页。两个页面需在同一浏览器、同一网站地址中打开。手机和电脑用同一配对链接，通过现有云端连接同步。

将下方程序上传至 Arduino Uno R3，关闭 Arduino 串口监视器，再点击“连接传感器”。每行只发送一个 A0 原始数值。默认波特率 9600。

void setup() {
  Serial.begin(9600);
}
void loop() {
  Serial.println(analogRead(A0));
  delay(20);
}

校准：先松手点击“记录松手值”，再用合适的力度按压并点击“记录按压值”。支持按压时数值上升或下降；显示的是相对压力，不是牛顿。

Uno R3 的 A0 读数范围为 0–1023。若是两脚裸薄膜电阻式压力传感器：5V → 传感器 → A0，另用一个 10kΩ 电阻从 A0 接 GND，作为起始分压方案。若是带模块的传感器，按模块说明接 VCC、GND、模拟输出 A0。A0 输入不得超过 5V。

在 map 页面双击可全屏，Esc 退出。关闭控制页或失去信号后，星云会自动回到静息状态。
